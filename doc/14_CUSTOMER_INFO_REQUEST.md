## 2. 결제·정산 (M2~M4 / Toss 연동 직전) ★★

테스트 결제·정기 후원 연동에 필요합니다. **가능하면 10월 중순(M4) 이전**에 회신해 주세요.

| # | 요청 항목 | 상세 | 관련 | ☐ |
|---|-----------|------|------|---|
| P1 | **토스 가맹점(상점) 정보** | 상점명 · 사업자 정보 · 테스트 상점 접근 권한(개발자 초대) | Q-50, T1 | ☐ |
| P2 | **정산 입금 계좌** | 은행 · 예금주 · 계좌번호 (라이브용은 별도 보안 채널) | Q-55 | ☐ |
| P3 | **정산 주기·주체** | 법인 통장 입금 후 내부 배분인지 등 한 줄 설명 | Q-55~56 | ☐ |
| P4 | **정기결제(자동결제) 사용** | Phase 1에 필수 — 계약에 빌링 포함 여부 확인 | T4 | ☐ |
| P5 | **간편결제(카카오페이 등)** | 수단별 **정기결제 지원 여부** · Phase 1 포함 범위 | v7 | ☐ |
| P6 | **해외카드** | Phase 1 필요 여부 | Q-52 | ☐ |
| P7 | **환불 정책** | 전액/부분 · 기간 · 선교사 캠페인 종료 시 처리 | Q-58 | ☐ |
| P8 | **결제 실패 시 운영 대응** | 재시도 안내 · 고객지원 에스컬레이션 | Q-58 | ☐ |
| P9 | **라이브 전환 일정** | 심사·실명 확인 담당자 · 목표일 (오픈 전) | T7 | ☐ |

**개발사에서 하는 일:** 테스트 키로 연동 · 웹훅 URL 제공 · 스테이징에서 검증.  
**고객에서 하는 일:** 가맹 계약 · 정산 계좌 · 라이브 키 발급·전달(보안 채널).
